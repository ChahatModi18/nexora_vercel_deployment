Built using **Bootstrap 5**, semantic HTML5, modern CSS3 animations, and vanilla JavaScript, designed with the assistance of Generative AI tools and prompt engineering.

## 🤖 Exact Generative AI Prompts Used

### Primary Generation Prompt:
```text
Act as a Principal Frontend Engineer and UI/UX Designer.
Develop a high-converting, modern, and fully responsive landing page for a startup named "Nexora" - an all-in-one productivity and collaboration platform.
Requirements:
1. Tech Stack: Semantic HTML5, Bootstrap 5.3 (via CDN), custom CSS with glassmorphism accents, and vanilla JavaScript.
2. Structure:
   - Sticky navigation bar with brand icon, navigation links (Features, How it Works, Pricing, Testimonials, FAQ), and CTA button.
   - Hero Section: Catchy headline ("Plan Better. Create Faster."), subtitle, interactive demo modal trigger, social proof badge, and interactive dashboard preview cards with live progress bars.
   - Core Features Grid: 6 modular cards highlighting workspace organization, automated sprint tracking, team sync, and smart notifications.
   - Interactive Demo / How It Works: Step-by-step visual workflow explaining how users organize projects.
   - Transparent Pricing Section: Tiered pricing cards (Starter, Pro, Enterprise) with interactive monthly/annual toggle and plan selection triggers.
   - Testimonials / Social Proof: Customer reviews with star ratings and avatar badges.
   - FAQ Accordion: Collapsible Bootstrap accordions for common inquiries.
   - Modern Footer: Multi-column links, newsletter subscription, and copyright notice.
3. Design System & Aesthetics:
   - Typography: Google Fonts (Manrope and DM Sans).
   - Color Palette: Soft light background (#f7f8fc), modern indigo/violet brand accent (#4f46e5), subtle border rings, and smooth hover micro-animations.
4. Interactivity:
   - Interactive task checklist updating live dashboard progress percentage in real time.
   - Modal popup for plan checkout and sign-in previews.
   - Smooth anchor scrolling and accessible ARIA attributes.
```

### Refinement & Enhancement Prompt:
```text
Enhance the responsive design of the Nexora landing page for mobile viewports (down to 320px). Add accessible skip-to-content links, optimize touch targets for mobile buttons, and implement responsive progress state calculation in JavaScript when task items are toggled.
```

## ✨ Key Features

- **Responsive Grid & Navigation:** Fully responsive Bootstrap 5 layout adapting seamlessly from 4K displays down to mobile devices.
- **Dynamic Interactive Task Dashboard:** Interactive checkboxes that dynamically recalculate and animate progress values and progress bars on the fly.
- **Bootstrap Interactive Modals:** Dynamic modal popups for trial enrollment and sign-in previews with context-sensitive plan data.
- **Glassmorphic Hero & Cards:** Modern CSS aesthetics with subtle borders, gentle shadows, and clean typography.
- **Accordion FAQ:** Smooth, accessible Bootstrap accordion components for common user questions.
- **SEO & Accessibility Ready:** Semantic tags, descriptive meta tags, ARIA labels, and skip links.

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic elements)
